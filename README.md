## 简介

阿哈酒馆是一个 DSH（DeepSeek Harness）插件，用来做角色扮演和互动叙事。它在 DSH 里增加一个"酒馆模式"：你和角色对话，剧情走到关键画面时自动生成一张图，角色的台词可以朗读出来。

生图和语音都使用你自己部署的外部服务，插件只负责编排，所有生成物只保存在本地。

## 特性（规划中）

- **角色扮演**：角色卡定义人设、文风与出场白；跨场次记得上一场的剧情
- **剧情生图**：按剧情调用 ComfyUI 出图，生图期间不打断对话；支持同一角色跨场景保持外貌一致
- **台词语音**：每个角色有固定音色，台词可自动或手动朗读
- **一图成卡**：给一张角色图，辅助生成可直接开场的角色卡
- **戏单存档**：每场结束生成剧情摘要、图集与音频清单，可整场回看

## 使用

进入酒馆模式后，用斜杠命令开场和收场，其余时间自由对话：

```
/aha 开场 星神☆阿哈(欠债版)
你就是阿哈帕？这是你的账单，快点还钱帕！
……
/aha 谢幕
```

子命令中英文等价，也可以写成独立命令：`/aha 开场` = `/aha start` = `/aha-start`。

| 命令 | 作用 |
|---|---|
| `/aha 开场 <角色名>` | 进入一场戏 |
| `/aha 换角 <角色名>` | 戏中切换角色 |
| `/aha 谢幕` | 收束存档，生成戏单 |
| `/aha 重掷 [修改词]` | 上一张图不满意，重新生成 |
| `/aha 朗读 [文本]` | 手动朗读 |
| `/aha 自检` | 检查生图与语音服务是否就绪 |
