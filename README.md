# 阿哈酒馆 Aha Tavern

> 听说那世界尽头的酒馆墙面写着"阿哈禁止入内"，这阿哈也太没有面子了。问题不大，咱直接开一个。

**状态：文字聊天、群聊、写书都可用，生图和台词语音也可用。** 已经能开店、建角色卡、写主角档案、和角色单聊、拉几个角色同台群聊、把聊过的故事写成书、让角色记事；配好 ComfyUI 后，角色还能按剧情画图；配好语音服务后，角色的台词可以念出来。真珠别催了，借我点免费算力跑一下呗。

## 简介

阿哈酒馆是一个 DSH（DeepSeek Harness）插件，用来做角色扮演和互动叙事。它在 DSH 里增加四个"酒馆模式"：酒馆:筹备（开店、建角色卡）、酒馆:单聊（和一个角色聊天）、酒馆:群聊（几个角色同台，有旁白）和酒馆:写书（把聊过的故事整理成书）。剧情走到关键画面时，角色可以调用你的 ComfyUI 画一张图。角色的台词也可以用固定的声音朗读出来。

生图和语音都使用你自己部署的外部服务，插件只负责编排，所有生成物只保存在本地。

## 特性

已实现：

- **角色扮演**：角色卡定义人设、文风与出场白；角色会记住你让它记的事，跨会话记得上一次的剧情
- **文字主题**：自带"愚者"（默认）与"直白"两套称呼风格
- **剧情生图**：按剧情调用 ComfyUI 出图，先画后说，图片显示在这一轮回复的第一行；也可以随时让角色画一张或重画。要先[配置生图](docs/image-setup.md)
- **照图建角色**：给掌柜一张角色图，他看图起草角色卡，接着用这张图定妆、按角色气质配声音（模型需支持图片输入）
- **角色外貌一致**：给角色定一张定妆图（三视图），之后画的图都照它来；需要时可以加多套形象
- **群聊**：几个角色同台，一个模型演全场，旁白交代环境，你可以用 `@角色名` 点名；换场、收场、群聊记忆都有，群聊里的事之后单聊时角色也记得
- **写书**：把聊过的几场整理成书。先出按场次排的整理稿，还可以再按你想要的文风改写成小说，最后导出 Markdown
- **台词语音**：每个角色有自己的声音（自备录音，或按描述让掌柜设计一个），台词可以手动朗读，也可以每轮自动朗读。苹果芯片的 Mac 上，插件能替你装好并启动本机语音服务。要先[配置语音](docs/voice-setup.md)

## 安装

尚未发布到 npm。目前用打好的 tgz 包安装：

```bash
dsh plugin --profile web add ./aha-tavern-0.0.1.tgz
```

装好后重启 `dsh web`，新建会话时就能在模式列表里看到"酒馆:筹备"、"酒馆:单聊"、"酒馆:群聊"和"酒馆:写书"。完整步骤见[使用指南](docs/getting-started.md)。

运行时需要：

- DSH
- 一个能用的模型（本地模型或在线模型都行）

想让角色画图，还需要一个 ComfyUI，配置方法见[配置生图](docs/image-setup.md)。想让角色开口，需要苹果芯片的 Mac 加 uv，或者一个自己部署的 OpenAI 兼容语音服务，配置方法见[配置语音](docs/voice-setup.md)。这两项都不配置也能正常聊天。

## 使用

先在"酒馆:筹备"里开店、建角色，再新开"酒馆:单聊"会话开场：

```
/aha 启动
/aha 角色 白狐
```

```
/aha 开场 星神☆阿哈(欠债版)
你就是阿哈帕？这是你的账单，快点还钱帕！
……
/aha 记忆 我不吃香菜
```

子命令中英文等价，也可以写成独立命令：`/aha 开场` = `/aha start` = `/aha-start`。

| 命令 | 在哪个模式 | 作用 |
|---|---|---|
| `/aha 启动` | 筹备 | 把当前工作区变成一间酒馆 |
| `/aha 角色 [角色名]` | 筹备 | 新建或修改角色卡 |
| `/aha 我` | 筹备 | 写或改主角档案 |
| `/aha 世界观` | 筹备 | 写或改世界观 |
| `/aha 定妆 [角色名]` | 筹备 | 给角色定一张定妆图，之后画的图都照它来 |
| `/aha 导入` | 筹备 | 从另一间酒馆复制角色卡或主角档案 |
| `/aha 开场 [角色名…] [情景]` | 单聊、群聊 | 单聊：选定角色开始聊天；群聊：定下谁在场、什么情景，开始一场 |
| `/aha 旁白 [要求]` | 群聊 | 让旁白改变环境或局面，例如 `/aha 旁白 让气氛紧张一点` |
| `/aha 换场 [新情景] [谁来谁走]` | 群聊 | 换一个场景，可以同时增减在场的人 |
| `/aha 收场` | 群聊 | 给这一场写梗概并起标题，之后还能接着聊 |
| `/aha 记忆 [内容]` | 单聊、群聊 | 记一句话，或让角色回顾并整理记忆；群聊里可用 `@角色名` 只记给某个人 |
| `/aha 写书 [书名]` | 写书 | 开一本书：选要收入的聊天与人称 |
| `/aha 进度` | 写书 | 看书写到哪了 |
| `/aha 停笔` | 写书 | 停下正在写的那一节，已写好的保留 |
| `/aha 导出 [整理稿\|小说]` | 写书 | 把整本书拼成 Markdown 文件；不带参数时两份都导 |
| `/aha 自检` | 都可以 | 检查当前状态；`/aha 自检 生图`、`/aha 自检 语音` 看详情 |
| `/aha 重新生图 [修改要求]` | 单聊、群聊 | 按原画面换一张；带上修改要求，角色会改写画面描述后重画 |
| `/aha 朗读 [文字\|开\|关\|停]` | 单聊、群聊 | 念上一条回复，或念给定的文字；`开` / `关` 切换这场聊天的自动朗读，`停` 停止朗读（也可写 `/aha 说话`） |
| `/aha 语音 [启动\|停止\|状态]` | 都可以 | 启动、停止或查看本机语音服务 |

中文子命令有几个同义写法，效果一样：`启动` 也可以写 `开店`、`开张`，`角色` 也可以写 `角色卡`、`建卡`，`记忆` 也可以写 `记住`。
