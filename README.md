# 阿哈酒馆 Aha Tavern

> 听说那世界尽头的酒馆墙面写着"阿哈禁止入内"，这阿哈也太没有面子了。问题不大，咱直接开一个。

**状态：一期（文字版）可用。** 已经能开店、建角色卡、写主角档案、和角色聊天、让角色记事；剧情生图与台词语音还在规划中。真珠别催了，借我点免费算力跑一下呗。

## 简介

阿哈酒馆是一个 DSH（DeepSeek Harness）插件，用来做角色扮演和互动叙事。它在 DSH 里增加两个"酒馆模式"：酒馆:筹备（开店、建角色卡）和酒馆:单聊（和一个角色聊天）。后续计划：剧情走到关键画面时自动生成一张图，角色的台词可以朗读出来。

生图和语音都使用你自己部署的外部服务，插件只负责编排，所有生成物只保存在本地。

## 特性

已实现（一期）：

- **角色扮演**：角色卡定义人设、文风与出场白；角色会记住你让它记的事，跨会话记得上一次的剧情
- **文字主题**：自带"愚者"（默认）与"直白"两套称呼风格

规划中：

- **剧情生图**：按剧情调用 ComfyUI 出图，生图期间不打断对话；支持同一角色跨场景保持外貌一致
- **台词语音**：每个角色有固定音色，台词可自动或手动朗读
- **一图成卡**：给一张角色图，辅助生成可直接开场的角色卡
- **群聊与写书**：多个角色同台、把聊天整理成书

## 安装

尚未发布到 npm。目前用打好的 tgz 包安装：

```bash
dsh plugin --profile web add ./aha-tavern-0.0.1.tgz
```

装好后重启 `dsh web`，新建会话时就能在模式列表里看到"酒馆:筹备"和"酒馆:单聊"。完整步骤见[使用指南](docs/getting-started.md)。

运行时需要：

- DSH
- 一个能用的模型（本地模型或在线模型都行）

生图（ComfyUI）与语音（OpenAI 兼容的语音合成端点）是后续版本的内容，现在不需要准备。

## 使用

先在"酒馆:筹备"里开店、建角色，再新开"酒馆:单聊"会话开场：

```
/aha 启动
/aha 角色 白狐
```

```
/aha 开场 星神☆阿哈(欠债版)
你就是阿哈帕？这是你的账单，快点还钱帕！
……
/aha 记忆 我不吃香菜
```

子命令中英文等价，也可以写成独立命令：`/aha 开场` = `/aha start` = `/aha-start`。

| 命令 | 在哪个模式 | 作用 |
|---|---|---|
| `/aha 启动` | 筹备 | 把当前工作区变成一间酒馆 |
| `/aha 角色 [角色名]` | 筹备 | 新建或修改角色卡 |
| `/aha 我` | 筹备 | 写或改主角档案 |
| `/aha 世界观` | 筹备 | 写或改世界观 |
| `/aha 导入` | 筹备 | 从另一间酒馆复制角色卡或主角档案 |
| `/aha 开场 [角色名]` | 单聊 | 选定角色，开始聊天 |
| `/aha 记忆 [内容]` | 单聊 | 记一句话，或让角色回顾并整理记忆 |
| `/aha 自检` | 都可以 | 检查当前状态 |
| `/aha 重新生图`、`/aha 说话` | 暂未实现 | 生图与语音上线后可用 |

中文子命令有几个同义写法，效果一样：`启动` 也可以写 `开店`、`开张`，`角色` 也可以写 `角色卡`、`建卡`，`记忆` 也可以写 `记住`。
